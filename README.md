# Вольт — інтернет-магазин аксесуарів

Навчальний клієнтський вебзастосунок на HTML, CSS і JavaScript без фреймворків і без етапу збирання.

## Можливості

- каталог із 18 товарів шести категорій;
- картки товарів із ціною, знижкою, рейтингом і наявністю;
- детальна картка товару в модальному діалозі;
- пошук за назвою, фільтри за категорією, брендом, ціною і наявністю, сортування;
- кошик зі зміною кількості, підрахунком суми та збереженням у `localStorage`;
- форма оформлення замовлення з перевіркою полів;
- адаптивна верстка для екранів від 360 px.

## Структура

```
index.html          розмітка сторінки
css/                стилі (base, catalog, filters, cart, responsive)
js/data.js          дані каталогу
js/filters.js       фільтрація та сортування (чисті функції)
js/catalog.js       виведення карток товарів
js/cart.js          модель кошика
js/format.js        форматування цін і тексту
js/app.js           ініціалізація та обробка подій
tests/              модульні (node:test) і наскрізні (Playwright) тести
```

## Локальний запуск

ES-модулі не працюють за протоколом `file://`, тому сторінку відкривають через локальний сервер:

```bash
npm start           # http://localhost:8080
npm test            # модульні тести
npm run test:e2e    # наскрізні тести (потрібен пакет playwright)
```

## Публікація

- **GitHub Pages:** Settings → Pages → Source: *GitHub Actions*; робочий процес `.github/workflows/pages.yml` запускає тести й публікує сайт після кожного надсилання в `main`.
- **Netlify:** Add new site → Import an existing project → вибрати репозиторій; параметри беруться з `netlify.toml`.

## Робота з гілками

`main` містить лише перевірений код. Кожна функція розробляється в окремій гілці `feature/<назва>` і зливається в `main` з комітом злиття (`git merge --no-ff`). Повідомлення комітів відповідають специфікації Conventional Commits.
